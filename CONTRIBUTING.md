# Contributing

Thank you for helping improve Open SEO Engine.

1. Open an issue describing a bug or proposed feature before major changes.
2. Work on a branch and keep pull requests narrowly scoped.
3. Run `python -m unittest discover -s tests -v` before submitting.
4. Add tests for new analyzers or crawler behavior.
5. Avoid adding vendor-locked APIs or proprietary code to the core.

Security issues should be privately reported to the repository maintainer rather than disclosed in public issues. The project is experimental and should not be offered as an unrestricted public URL-fetching service.
